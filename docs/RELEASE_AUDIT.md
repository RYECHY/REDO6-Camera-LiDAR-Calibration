# 发布前核对与已知限制

核对日期：2026-09-30。依据用户提供的原始审核包进行文件与参数检查，不连接机器人、不启动标定器或训练。

## 1. 最终参数一致性

- 最终 YAML、原始参数导出和独立投影脚本中的 R/t 一致。
- 独立投影脚本使用与最终 YAML 相同的 K 和五项 D。
- 旋转数值接近 SO(3)，逆变换平移与四元数和前述坐标方向一致。
- 原始导出文件的 K/D 精度比最终 YAML 低，数值在输出舍入范围内相符。
- 原始文件 SHA-256 与用户提供的审核清单一致；公开原始资产保持字节不变。

## 2. RMSE 来源

最终 YAML 记录 `rmse_m: 0.0041`，但 `results/calib_result.txt` 只包含参数，没有这条误差值。审核包缺少原求解日志及残差计算实现，无法在本次核对中确认其完整口径。

因此公开说明使用“最终 YAML 记录的 RMSE”，不称作平均像素投影误差，也不以它声称所有距离和运动场景的准确度。

## 3. 相机标签与畸变差异

原标定器参数的相机注释误写了旧相机型号。公开模板修正注释，所有数值保留。输入/输出路径改成明确占位符。

历史 FAST-LIVO2 相机配置只包含四项畸变，而最终 YAML 和独立投影脚本包含五项。公开包保留差异，不把两者写成完全等价的相机模型。

## 4. 旧参考脚本的限制

三个历史助手脚本按原始字节保留，不重新包装成已经经过本次实机测试的软件：

| 脚本 | 限制 |
|---|---|
| 投影 | 最新图像策略，没有时间差门限；硬编码参数；强制帧名；没有运动补偿 |
| 彩色点云 | 最新图像取色；假设固定字段布局和本机 FLOAT32 数据解释；不能混用不同坐标的对应话题 |
| 原始点云转换 | 强制 `livox_frame`，输入必须真的是该坐标；只提供格式转换 |

最新图像策略可能把不同时间的数据关联起来。静态演示成功不能替代动态同步验收。

## 5. 本次新写的代码

- `check_calibration.py`：通用参数检查和逆变换计算；只打印 TF 命令，不执行。
- `analyze_correspondence_bag.py`：通用 ROS bag 字段与数据合法性检查；没有重新分析用户原始结果包。
- `validate_livo.launch.py`：公开启动示例；需要外部程序和完整配置，未在 ROS 环境执行。

原采集脚本的作者来源未能从已有记录核实，因此未纳入公开代码。历史消息转换桥接和相机内参求解脚本也未随包提供。

## 6. 复现层级

| 层级 | 当前公开包提供什么 | 尚缺什么 |
|---|---|---|
| 理解标定结果 | 最终 YAML、原始导出、现场图、方向说明 | 不需要内部工程 |
| 检查参数数学合法性 | 本地工具和真实参数 | 准确性仍需实测 |
| 静态独立投影参考 | 助手历史投影/点云脚本 | 自己的驱动、相机与点云数据、坐标核实 |
| 重新求解外参 | 标定模板、方法说明、确切上游和两个修改补丁 | 自己的输入数据、依赖及完整运行配置 |
| 原 FAST-LIVO2 输出复现 | 历史报告、确切上游、三文件修改补丁、相机配置、QoS 和启动示例 | 完整配置、录包、依赖与运行验收 |
| 部署到另一台设备 | 无对应设备的有效外参 | 该设备自己的安装标定与验收 |

用户最终标定数据是允许公开的结果；公司工程源码并没有因为参数公开而被纳入仓库。
