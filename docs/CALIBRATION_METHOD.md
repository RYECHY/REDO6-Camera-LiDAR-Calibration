# 相机—LiDAR 标定、投影与验收

本文介绍通用流程；本项目的最终参数和实际验证图见仓库 README。本仓库没有外参求解器；下列操作需在自己拥有的设备、数据和独立求解器中实施。

## 1. 明确标定对象与输入

RGB 相机提供二维图像，LiDAR 提供三维点。标定要估计两套坐标系之间的固定刚体变换，以便把同一个三维点投影到图像。

| 输入 | 应核对的内容 |
|---|---|
| 相机图像 | 原始尺寸、时间戳、帧名、镜头焦距、是否被裁剪或去畸变 |
| 相机参数 | K、D、畸变模型，以及参数对应的图像处理链 |
| LiDAR 点云 | 消息类型、xyz 单位、帧名、扫描时段和过滤过程 |
| 标定目标 | 实测尺寸、目标坐标系、点或圆心编号、正反面 |
| 求解程序 | 公开来源、版本、配置和本地修改 |

“圆筒外壳”描述的是外观，不代表相机提供深度，也不能据此外观自动选择鱼眼模型。相机模型应由真实成像与标定结果决定。

## 2. 准备相机内参与图像

针孔相机内参为：

\[
K=\begin{bmatrix}f_x&0&c_x\\0&f_y&c_y\\0&0&1\end{bmatrix}.
\]

五参数 `plumb_bob` 常用顺序为 `[k1,k2,p1,p2,k3]`。不得只按 YAML 中数字数量猜测模型。如果某个程序只读取四个参数，需记录其与五参数模型的差异，并独立验证边缘投影。

处理图像时注意：

- 原始畸变图像需要使用匹配的 K/D，或先进行一致的去畸变。
- 去畸变后应使用新图像对应的 K；不能只是把原来的 D 置零。
- 以 `sx, sy` 缩放图像时，焦距与主点分别按相应方向缩放。
- 裁剪起点为 `(x0,y0)` 时，主点也要扣除裁剪偏移。
- 相机预处理变化后，即使输出尺寸相同，旧 K 也可能不再匹配。

相机内参通常需要多张覆盖不同位置与姿态的标定图像。应保证标定板清晰、完整，避免图像全部集中在画面中央。

## 3. 采集相机与点云

1. 牢固固定相机与 LiDAR。标定期间两者不能发生相对位移。
2. 放置尺寸已知、两种传感器都能检测的标定目标。
3. 检查图像清晰度、曝光、遮挡和点云覆盖。
4. 保存原始输入、消息头与时间戳。
5. 记录点云是否由多帧累积而成，以及所用时间范围。
6. 数据转换时保留原始坐标与时间含义；转换消息格式不应隐含改变外参方向。

静止目标可以减轻时间差影响，但不能由静态标定推断动态场景已经同步。机器人运动和 LiDAR 扫描时段会带来额外时空误差，需在后续运行阶段单独评价。

## 4. 提取标定特征

以带圆孔或圆形目标的标定板为例，通常涉及相机侧圆心/标记检测和 LiDAR 侧平面、边缘及圆心提取。具体算法取决于所用求解器，不同标定板不能共享未经核对的尺寸或编号。

LiDAR 侧可以依次处理：空间 ROI → 平面提取 → 平面坐标表示 → 边缘提取 → 聚类 → 圆拟合。应保存每个阶段的点数、参数、失败原因和中间可视化。

标定时的 ROI 用来隔离标定板，不应被自动沿用为实时感知视场。标定板位置改变后也应重新检查 ROI。

配置中的目标半径是输入模型参数，拟合出的半径是结果，两者必须区分。差异过大时应核对板尺寸、边缘质量、单位和拟合方法，不能因为最终优化残差小就忽略差异。

## 5. 建立对应并求解外参

目标特征应在两传感器中有明确的一一对应，记录相同编号。错误排列可能产生数值上看似合理的刚体变换。

当两侧都已获得三维目标特征时，可基于对应的三维点估计刚体变换；若采用三维点到二维特征的重投影方法，则求解目标与残差定义不同。不能把所有求解器的 RMSE 都称作像素误差。

输出至少包括：

- 完整精度的 R、t，及外参方向、单位。
- 特征编号、有效点数与实际使用的数据。
- 求解器版本与参数文件。
- 优化目标和误差统计的定义。
- 检测与投影可视化。

原始数值和日志应独立保留。公开版参数可以移除内部路径，但不能悄悄改变数值，再声称它是原始结果。

## 6. 检查矩阵和物理尺度

合法旋转应满足 `R^T R ≈ I`、`det(R) ≈ +1`。矩阵数值合法只是必要条件，仍需要检查传感器安装距离与姿态是否符合真实设备。

低内部残差可能来自错误的内参尺度或错误的特征模型。相机与 LiDAR 对同一标定板的距离估计、实际安装间距以及投影结果应相互支持。

本仓库检查工具的 `1e-5` 默认容差是数值合法性检查容差，不是通用精度标准。真实误差阈值应按任务距离、视角、点云稀疏度和评估方法制定。

## 7. 独立投影验证

对 LiDAR 点 `p_L`，先计算 `p_C = R_CL p_L + t_CL`，再按相机模型投影。

1. 去掉非有限三维点。
2. 检查相机深度 `Z_C` 为正。
3. 使用与输入图像匹配的 K、D 和分辨率。
4. 检查像素范围与可见目标边缘。
5. 同时保存原图、叠加图和输入时间戳。
6. 在中心、左右边缘、不同距离和非标定板目标上验证。

“像素没有越界”只证明输出在图像内，不证明投影落在正确物体上。单张图也不能证明全天候、运动场景或整个视场都准确。

## 8. 记录验收证据

| 指标 | 应记录的证据 | 不能替代什么 |
|---|---|---|
| 求解器残差 | 定义、单位、样本数、原始日志 | 独立场景的投影精度 |
| 重投影误差 | 明确配对的几何特征、像素距离统计 | 时间同步和动态稳定性 |
| 消息完整性 | 帧数、非有限值、越界、正深度检查 | 点与物体的正确关联 |
| 运行表现 | 持续时间、频率、延迟、失败帧 | 标定空间精度 |
| TF 检查 | 正反向变换、帧名、发布者、时间 | 输入图像模型正确性 |

可统计均值、中位数、95 分位数和失败率，但应先定义样本及失败条件。不同输入、不同算法或不同过滤参数的结果不能直接混用。

## 9. 常见现象与检查方向

| 现象 | 优先检查 |
|---|---|
| 中心尚可、边缘错位明显 | 畸变模型、去畸变后的 K、缩放与裁剪 |
| 大部分点投到画面外 | 外参方向、坐标轴、输入点所在帧 |
| 静止准确、运动时重影 | 时间差、扫描时段、运动补偿 |
| TF 数值符合预期但投影错误 | 光学帧定义、图像模型、输入坐标是否已变换 |
| 有话题但节点收不到数据 | 消息类型、QoS、时钟和订阅配置 |
| 内部 RMSE 很小、安装距离不合理 | 特征模型、单位、内参尺度与特征顺序 |

应先隔离静止单帧图像与点云完成投影，再逐步接入实时链路。每次只调整一个原因，并保存前后结果。
