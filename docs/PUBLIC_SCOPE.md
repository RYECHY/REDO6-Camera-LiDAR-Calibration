# 公开内容与排除范围

按用户明确的发布范围构建：公司现场照片可以公开，用户最终得到的标定参数可以公开，助手编写的项目代码可以公开；同时允许注明上游来源、版本和许可并提供可公开的标定修改补丁。内部账号、路径和公司源码不公开。

## 已公开

- 用户最终外参、相机内参、原始参数导出与相关标定配置。
- 标定目标检测图、标定板投影图和历史离线叠加图。
- 已有助手编写记录支持的三个投影/点云参考脚本。
- 本次独立编写的参数检查、离线检查和启动示例。
- 重新组织的公开方法说明及历史报告摘录。
- 对确切公开上游基线核对过的 FAST-Calib 两个补丁、FAST-LIVO2 一个补丁与各自 GPL-2.0 许可。

## 未公开

- 内部用户名、登录账号、主机名、局域网地址和个人绝对路径。
- 公司私有导航、控制及算法工程；本次单独审核的公开上游补丁不包含这些工程。
- 完整第三方工程，以及没有取得内容或没有完成来源核对的其他修改。
- 继承自设备工程的其他传感器安装参数。
- 原始审核清单、原始审核包、公司私有版本记录与未审核补丁。公开上游版本及已审核补丁另有明确记录。
- 原始 rosbag、PCD、模型权重、运行日志与完整数据集。
- 作者来源未能核实的历史采集脚本。

参数模板中出现 `REPLACE_WITH_...` 是明确占位符，文档中的“你自己的工作空间”是操作提示，均不是内部实际路径。

本目录按白名单重新构建，没有把原审核包或第三方目录直接发布。公开 README 说明复现缺口，避免把没有源码和数据的资料仓库写成已经完整开源的工程。

本次没有向 GitHub 实际上传。上传时只使用本目录；不要从原审核包或原工作空间执行 `git add .`。
